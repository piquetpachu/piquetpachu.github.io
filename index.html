Hola, soy Nacho 👋

Desarrollador web con enfoque en frontend y backend, orientado a la creación de aplicaciones web claras, funcionales y bien estructuradas. Trabajo con HTML, CSS, JavaScript, PHP y Python, utilizando bases de datos MySQL y control de versiones con Git.

He desarrollado proyectos académicos y personales aplicando arquitectura CRUD, diseño MVC y consumo y creación de APIs REST. Entre ellos se encuentran un sistema de gestión de stock para una tienda de motos, una aplicación web de librería y un gestor de entrenamientos para gimnasio.

Me adapto rápidamente a nuevas tecnologías y entornos de trabajo. Busco mi primera oportunidad profesional en IT o proyectos freelance donde pueda seguir aprendiendo y aportar valor desde el primer día.
